Kebijakan Privasi

Aplikasi MGS YouTube Autopost hanya mengakses akun YouTube milik pengelola MGS Computer, dan hanya untuk mengunggah serta menjadwalkan video. Aplikasi tidak mengumpulkan, menyimpan, menjual, atau membagikan data pengguna lain.

Token akses disimpan terenkripsi di GitHub Secrets milik pengelola dan dapat dicabut kapan saja melalui pengaturan akun Google (myaccount.google.com/permissions).

Penggunaan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

Privacy Policy

The MGS YouTube Autopost application only accesses the YouTube account owned by the operator of MGS Computer, solely to upload and schedule videos. It does not collect, store, sell, or share any other user's data.

Access tokens are stored encrypted in the operator's GitHub Secrets and can be revoked at any time via Google Account settings (myaccount.google.com/permissions).

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
